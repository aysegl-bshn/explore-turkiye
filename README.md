## 🇬🇧 English

### 📌 About the Project

**Explore Türkiye** is a modern and responsive tourism website designed to introduce different tourist destinations and natural attractions across Türkiye.

The project was developed to improve frontend development and web design skills.

### 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Web Design
* CSS Animations
* CSS Transitions
* CSS Hover Effects
* 3D Card Effects
* Parallax Effect
* Dropdown Menu

### ✨ Features

* Responsive design
* Sticky navigation bar
* Dropdown city menu
* 3D flip cards
* Hover effects
* CSS animations
* Parallax sections
* Tourist destination sections
* Image gallery
* Tour packages
* Contact section
* Mobile-friendly layout

### 🎯 Project Purpose

The purpose of this project is to introduce tourist destinations in Türkiye through a modern web interface while improving frontend development skills using HTML5 and CSS3.
